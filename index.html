SRLTA — Sim Racing Lap Time Analyzer (In Progress)

A professional-grade Python telemetry analysis tool for Assetto Corsa. Compares lap times using multi-channel data (speed, throttle, brake, lateral G) to identify where time is gained or lost corner-by-corner. Features MoTeC-style visualizations, automated coaching feedback, and support for SimHub and AC Shared Memory formats.

  • Accurate delta calculation via time-based interpolation
  • Advanced corner detection with entry, apex, and exit identification
  • Professional telemetry plots with gain/loss coloring
  • Automated sector analysis and coaching insights
